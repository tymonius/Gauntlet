Deck Prep.

Create one request link, let players choose through the normal new-player onboarder, then print and prepare exactly what each person requested.

No game-session ceremony

A Deck Prep list does not create tables, seats, QR cards, tracked games, or Rules Arbiter links. It exists only to prepare materials before play.
