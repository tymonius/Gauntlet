Self-serve playtest · v0.7.0

One player creates the game.

The creator receives a public join link and QR code. Both players join from their own devices so faction choices, Rules Arbiter questions, live observations, and individual questionnaire responses stay attached to the same game.

  1. Create the game using your faction and Leader.
  2. Let the opponent scan the QR code and confirm their own choice.
  3. If you're together in person, use the physical tabletop. If you're in different locations, use Tabletop Simulator.
  4. The creator records the start once, then both players play normally.
  5. The creator submits the shared result; both players submit separate individual responses.

No account is required. The public join code cannot read questionnaire answers. A separate review key is saved only for the game creator.

Already finished the game? Create a retrospective record if both players can still join that record.

Just need to send your own feedback? Use the standalone feedback form; no tracked session or second player is required.

Table companion

Keep the sequence visible.

Turn sequence
  1. Capture — advance the Front Line when eligible.
  2. Draw — draw one card.
  3. Opening — take your Action now or save it.
  4. Movement — Advance, Hold, or Fall Back; entering the opponent's Position begins Onset.
  5. Denouement — take your Action here if you did not take it during Opening.
  6. Cleanup — end-of-turn effects and Hand limit.
Battle sequence
  1. Onset
  2. Set Gambits
  3. Form Reserves
  4. Reveal Gambits
  5. Choose Tactics
  6. Reveal Tactics
  7. Outcome
  8. Aftermath
First-battle reminders
  • Terms, when applicable, resolve first during Onset.
  • Gambits are set from Hand; Reserves are private three-card battle draws.
  • Tactics are chosen from Reserve.
  • Defensive Edge wins tied battle totals for the defender; an unresolved tie uses a separate unmodified Tiebreak Roll.
  • Normal Gambits go to the Graveyard, Tactics to Discard, and unused Reserve cards to Discard during cleanup.
