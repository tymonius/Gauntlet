Organizer instructions

Host a complete game-night playtest.

Follow these phases in order. Each phase ends with a visible checkpoint so you know it is safe to continue.

Open Host Home
1. Create 2. Invite 3. Monitor 4. Prepare 5. Make QR codes 6. Start games 7. During play 8. End games 9. Next round 10. Close event
01

Before invitations

Create the game-night event.

  1. Open Host Home in the normal browser profile you will use to organize the event.
  2. In Create a game-night event, enter an optional event label and the facilitator creation key.
  3. Select Create and open event.
  4. Wait for the private Event Dashboard to open.
  5. Use the Host Home link in the dashboard navigation to confirm the event was saved in this browser.
Checkpoint: Host Home lists the event and its Event Dashboard button works.
Keep organizer links private. Never send a URL containing host=. Do not use Host Home on a public or shared computer.
02

Before the selection deadline

Invite participants.

  1. Open the event from Host Home.
  2. Select Copy participant link.
  3. Send that public link to everyone expected to attend.
  4. Tell participants when their selection is due and that their prepared Deck will be based on their latest submission.
Suggested invitation

Choose your Gauntlet faction and Leader before game night. Read the First Game Introduction and submit your selection so your Deck and components can be prepared for you.

Do not send: the Event Dashboard URL, Registration Controls, a table URL before it is needed, or any URL containing host=.

03

While participants choose

Monitor the roster.

  1. Open the Event Dashboard and select View roster.
  2. Select Refresh roster whenever you need current results.
  3. Review Choices submitted for each participant’s latest faction and Leader.
  4. Follow up with anyone under Joined, not submitted near the deadline.
  5. Use Participant preview only to inspect the public experience; do not join the event as a player from the organizer URL.
Checkpoint: Every expected participant either has a submitted choice or has been intentionally marked as a late addition.
04

At the selection deadline

Freeze choices and prepare materials.

  1. From Host Home, open Registration controls for the event.
  2. Select Close session to stop new onboarding submissions and revisions.
  3. Return to the Event Dashboard and select Download CSV.
  4. Prepare one complete player set for every submitted choice.
  • Selected faction and Leader
  • Prepared or recommended Deck
  • Three Territories
  • Player Token
  • Faction and Leader components
  • Reference material and one six-sided die

Closing event registration does not prevent the organizer from creating child table sessions afterward.

Checkpoint: The physical player sets match the final roster CSV.
05

Before players sit down

Create one QR code for each game.

A QR code represents one individual game—not one physical table for the entire evening.

  1. Open Table sessions on the Event Dashboard.
  2. Enter the number of games you expect, including later rounds and one or two reasonable spares.
  3. Select Create table codes and confirm.
  4. Select Print QR cards.
  5. Select Download table manifest as a recovery and browser-transfer backup.
  6. Check that every card has a unique table number, serial, readable QR code, and instruction for both players to scan it.
4 tables · 1 roundCreate at least 4 codes.
4 tables · 2 roundsCreate at least 8 codes.
Uncertain attendanceAdd 1–2 spare codes.
Checkpoint: Every intended game has a distinct printed QR card, and Host Home lists the saved table links.
06

At each table

Seat players and start the game.

  1. Place one unused QR card at the table.
  2. Have both players scan the same code.
  3. Each player selects their recognized name or chooses themselves from the event roster, then selects Join game.
  4. On the Event Dashboard, select Refresh games.
  5. Confirm the correct two names, factions, and Leaders appear and the table status is Ready.
  6. Choose one player as the session recorder. That player selects Game started once.
Unused
No player has joined.
Joining
One seat is occupied.
Ready
Both seats are occupied.
Closed
The QR code is retired.
Checkpoint: The dashboard shows two correct players and Ready before play begins.
07

During play

Keep the digital record attached to the correct game.

  1. Players remain on their own joined Table Session pages.
  2. When a rule or card interaction is unclear, the player asking selects Ask the Rules Arbiter from their own device.
  3. Use the physical playtest sheet to record timing, outcome, warnings, ratings, and qualitative observations.
  4. Use Quick session note for a notable event that should be attached to the digital game record.

Questions submitted through a joined device are automatically linked to the table session and the player who asked them. No one needs to re-enter a session code.

Record before diagnosing. Capture what happened during the game before debating a balance change or redesign.
08

When a game ends

Finish, collect feedback, and retire the QR code.

  1. For a completed game, the designated recorder selects Game completed.
  2. For a stopped game, select the correct stop reason and then Record stopped game.
  3. Have both players finish their portions of the physical playtest sheet.
  4. Collect the sheet.
  5. Return to the Event Dashboard and select Refresh games.
  6. Confirm the correct players are attached to the correct table.
  7. Select Close game and confirm the serial.

Closing preserves the game record but prevents new joins, additional game events, and reuse of that QR code.

Checkpoint: The physical sheet is collected and the dashboard marks the game Closed.
09

For every later round

Use a fresh QR code.

A second game always uses a new code, even when the same players, matchup, or physical table are reused.

  1. Place a new unused QR card at the table.
  2. Both players scan and join again.
  3. Verify both seats on the Event Dashboard.
  4. Repeat the start, play, feedback, and closure steps.

This keeps every game’s players, questions, timing, events, outcome, and feedback analytically separate.

10

After the final game

Close the event cleanly.

  1. Collect every physical playtest sheet.
  2. Select Refresh games on the Event Dashboard.
  3. Close every completed, abandoned, or unused table session that will not be used later.
  4. Confirm no live game remains open accidentally.
  5. Retain the roster CSV, table manifest, physical sheets, and saved event entry in Host Home.
  6. Use Forget event only when you no longer need that browser shortcut. Forgetting does not delete server records.
  7. Create a fresh event for the next independently organized game night.
Final checkpoint: All physical feedback is collected and every table code is either intentionally open or closed.

One-page host checklist

Game-night control sheet

Participant instructions

Choose, join, play, and finish.

You do not need an account or password. Before game night you submit one choice; at the table you scan one QR code and confirm who you are.

Before

Before game night

Submit the choice the organizer should prepare.

  1. 1
    Open the invitation.

    Use the participant link sent by the organizer. No account, password, or manually entered session code is required.

  2. 2
    Enter your name.

    Use the name the organizer will recognize at game night.

  3. 3
    Explore the six factions.

    Read the short summaries and open full guides for the factions that interest you. You do not need to read every guide.

  4. 4
    Choose a faction and Leader.

    Select one faction, then one of its two Leaders.

  5. 5
    Read the First Game Introduction.

    Read it in order. The complete Rulebook and Rules Arbiter remain available during play.

  6. 6
    Submit your choice.

    Check the confirmation box, select Submit my choice, and wait for confirmation that your selection is on the roster.

Changed your mind? Reopen the same invitation before the deadline and select Revise my choice. The organizer sees only your latest submitted choice.
At table

At game night

Join the correct game before play begins.

  1. 1
    Collect your prepared materials.

    The organizer should provide the Deck and components for your submitted faction and Leader.

  2. 2
    Both players scan the same table QR code.

    Do not scan a neighboring table’s code or reuse a code from an earlier game.

  3. 3
    Confirm who you are.

    When the page says Playing as [name]?, select Join game. When it asks Who are you?, select your name from the roster and then join.

  4. 4
    Check your seat.

    The connected panel must show your name, faction, Leader, and seat. Tell the organizer immediately when anything is wrong.

  5. 5
    Wait for both players.

    Do not begin until both seats are joined and the organizer confirms the table is ready.

  6. 6
    Record the start once.

    One designated player selects Game started. The other player does not select it again.

I am not on the roster is for genuine late additions who did not complete onboarding.

During

During play

Ask from your own joined device.

  1. When a rule, card, timing question, or interaction is unclear, select Ask the Rules Arbiter.
  2. Ask the question from your own device so it is attributed to you rather than your opponent.
  3. Record useful observations on the physical playtest sheet.
  4. Describe what happened before debating a balance fix.
Your question is linked automatically.The system records this game and the player who submitted it; you do not need to type a session code.
After

After the game

Finish the record before leaving the table.

  1. One designated player selects Game completed. For a stopped game, record the correct stop reason instead.
  2. Complete your ratings and written feedback on the physical playtest sheet.
  3. Return the sheet to the organizer.
  4. For another game, scan the new QR code supplied by the organizer. Never reuse the previous game’s code.

One-page player quick-start

At the table

  1. Both players scan the same unused QR code.
  2. Confirm your own name and select Join game.
  3. Check your displayed seat, faction, and Leader.
  4. Wait until both seats are joined.
  5. One player records Game started.
  6. Ask the Rules Arbiter from your own joined device.
  7. One player records completion or the stop reason.
  8. Finish and return the physical feedback sheet.

Troubleshooting

When the expected screen does not appear.

Most problems are resolved by identifying the page, browser, or session state involved.

Host Home is empty.

Open the private Event Dashboard once in the same normal browser, then return to Host Home. On another browser or device, restore table links from the manifest.

The table link is missing on this computer.

The public table token is retained by the browser where it was created. Use that browser or import the table manifest into Host Home.

My name is not in the table dropdown.

Return to the onboarding invitation and complete the faction and Leader submission. Ask the organizer to refresh the roster. Genuine late additions may use I am not on the roster.

The page recognizes the wrong player.

Select Not you?, choose the correct roster entry, and join again.

The table already has two players.

That game session is full. Ask the organizer for a fresh table QR code.

The game is closed.

Closed QR codes are retired and cannot be reused. Ask the organizer for a new code.

A Rules Arbiter question was not attributed correctly.

Make sure the player joined the Table Session before opening the Rules Arbiter and asked from their own device.

The organizer page looks like a player page.

Return to Host Home and open Event Dashboard. Organizer URLs contain a private host= parameter and should never be distributed.
