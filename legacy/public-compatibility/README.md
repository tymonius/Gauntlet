# Historical public compatibility surfaces

This subtree is the canonical repository source for retired browser applications and compatibility landings that still have stable public URL contracts.

The preserved public compatibility sources are:

- `rulebook/` — retired `/rulebook/` route, which redirects to the active `/rules/` architecture while frozen release artifacts preserve historical Rulebooks.
- `deckbuilder-v0.5/` — historical pre-faction Deckbuilder.
- `deckbuilder-v0.6/` — historical faction-era Deckbuilder.
- `faction-sheets/` — retired printable faction-sheet browser surface.

GitHub Pages stages these sources back to their established public URLs. Their repository location is historical; their deployed URL contracts remain stable where compatibility is intentional.

Nothing in this subtree is current gameplay or rules authority. New product behavior belongs in current applications and authority sources, not here. Changes should be limited to explicit compatibility or preservation fixes.
