Poetica ornament index study

Poetica exposes its ornaments as OpenType alternates of the bullet character. Each tile below keeps the source text as U+2022 and changes only the numeric selection index passed to font-feature-settings: "ornm" N.

Index 0 is the unmodified bullet baseline. Indexes 1–64 test the webfont's alternate set directly beneath the Declaration Blackletter Deed wordmark. If the historical supplemental ornaments were folded into Poetica Std, they should appear here as distinct numbered alternates.

Once the sequence stops producing distinct ornaments and begins repeating or falling back, later indexes can be ignored. The selected ornament can then be reproduced exactly with the same ornm index on a bullet character; no image asset is required.
