# Archived digital-engine dev runners

This subtree preserves two unreferenced pre-faction/v0.5.6 development runners that previously lived at generic source paths:

- `src/cli/dev-runner.ts`
- `src/gui/dev-server.ts`

They were archived byte-for-byte as `.ts.txt` provenance files so they cannot be mistaken for maintained TypeScript entrypoints or pulled into the active compiler surface.

The maintained legacy interactive runners remain explicitly versioned under `src/cli/dev-runner-v06.ts` and `src/gui/dev-server-v06.ts`, exposed only through the `dev:legacy:*` package scripts.

Nothing in this subtree is current gameplay authority or an executable development surface.
