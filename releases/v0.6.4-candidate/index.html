What this record is

v0.6.4-candidate was never a public numbered release. It was the approved source bundle used to assemble v0.7.0. This archive preserves that intermediate state without creating a retroactive Git tag or GitHub Release.

The archive is pinned to pre-cutover commit 268b6b3bfd6a5d3bf6ac97de815ab7af93cd69b3, where game-data/current-game.json identified the active-development authority as v0.6.4-candidate over the v0.6.3 baseline.
