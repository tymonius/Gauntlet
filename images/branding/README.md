# Branding assets

This directory contains source/reference branding assets that are not themselves current runtime path contracts.

Current production consumers still reference `images/Gauntlet.svg` and `images/Gauntlet-G.svg`; those files remain at their existing paths until their consumers are deliberately migrated.

The unreferenced Illustrator/PNG wordmark source files are retained here as design-source/reference material rather than as runtime assets.

Unreferenced branding source files should live here rather than at the repository root.
