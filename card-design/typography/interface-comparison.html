Interface typeface study

Inter, Segoe UI, and Roboto.

Same strings, sizes, weights, tracking, and component geometry. Only the interface typeface changes. The specimens below reproduce the roles Gauntlet currently assigns to the interface face: navigation, labels, metadata, controls, compact status text, catalog machinery, and card utility text.

Segoe UI is served by the Gauntlet Adobe Fonts project. The comparison therefore uses the same webfont on Windows, Android, and headless rendering instead of depending on a locally installed system copy.
