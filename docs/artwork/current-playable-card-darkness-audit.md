# v0.7.2 — Current playable-card artwork darkness audit

> A **quantitative darkness ranking, not a judgment of whether each scene needs correction.** This report covers all 142 current playable cards; it excludes Territory and supplemental cards.

- Source: `packages/game-data/current-game.json` on the audit branch, with current original illustrations from `images/artwork/cards/`.
- Method: each source image decoded with Pillow, downsampled to fit 256 × 256, then measured using 8-bit sRGB weighted luminance `Y = 0.2126R + 0.7152G + 0.0722B`.
- Ranking: ascending mean luminance (0 = black; 255 = white). `Dark pixels` means luminance below 64.
- These measurements **do not** automatically predict print quality: subject isolation, local contrast, and dark-light separation also matter.
- Report generated by GitHub Actions audit run: https://github.com/tymonius/Gauntlet/actions/runs/43384190864
