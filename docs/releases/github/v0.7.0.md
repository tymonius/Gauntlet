# Gauntlet v0.7.0 — Illustrated Cards & Tabletop Simulator

**Release candidate — not yet published**

Gauntlet v0.7.0 is the first release candidate built around the fully illustrated production card set and the complete Tabletop Simulator package. It preserves the approved current-game source provenance while promoting the assembled product identity to v0.7.0.

## Release highlights

- 142 playable cards, 25 Territories, six factions, twelve Leaders, and twelve starter Decks;
- complete current playable-card artwork with production card layouts and current Territory artwork;
- finalized shared and faction reference material, including the Universal Reference Card;
- production supplemental components for all six factions, including trackers, Diplomat Proposals/Treaty Articles, Financier Capital Ledger and Deeds, Mystics Rites, and Inquisition reference material;
- a v0.7.0 Tabletop Simulator package with all twelve starter kits, the shared Universal Reference, and faction supplemental components assembled into each starter Bag;
- deterministic hosted-asset staging and machine-readable TTS release-readiness checks; and
- guarded promotion from the generated TTS Review Scaffold to the final Workshop save only after explicit in-game QA.

## Tabletop Simulator

The current v0.7.0 TTS build is machine-ready. The latest full package generation produced 28 ready supplemental component definitions, 80 assembled supplemental objects, and 75 staged network assets with no machine-readiness blockers.

The TTS implementation intentionally remains a digital tabletop rather than a rules engine. Players perform setup, battle resolution, card handling, and faction procedures themselves. Final Workshop publication remains gated on the versioned manual-QA checklist and a complete remote two-player validation game.

## Release boundary

This file describes the **v0.7.0 candidate**. It does not change the repository's current published release, create or move a Git tag, create a GitHub Release, publish TTS hosted assets, or publish the Workshop mod.

Until final cutover, v0.6.3 remains the current published playtest release. The v0.7.0 candidate continues to use the approved current-game source bundle and preserves its source-version provenance separately from the v0.7.0 product/package identity.

Release closeout and TTS/Workshop QA are tracked in [#851](https://github.com/tymonius/Gauntlet/issues/851).
