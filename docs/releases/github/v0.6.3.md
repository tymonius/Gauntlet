# Gauntlet v0.6.3 — Third Playtest Revision

**Current canonical playtest edition**  
**Clean publication cutover:** August 14, 2026  
**GitHub Release record:** August 15, 2026

Gauntlet v0.6.3 is the clean reconstructed third playtest revision. It replaces the withdrawn original v0.6.2/v0.6.3 authority chain with a self-contained release rebuilt from the trustworthy v0.6.1 baseline plus audited, explicitly adopted v0.6.2 and v0.6.3 changes.

## Release highlights

- 128 playable cards, 25 Territories, six factions, and twelve Leaders;
- revised opening setup and the independent final-Territory and Last Stand normal victory routes;
- the audited v0.6.3 timing, battle, Front Line, card-role, Asset, and faction procedures;
- twelve rebuilt starter Decks and synchronized first-game onboarding;
- current Browser Rulebook, Card Reference, Deckbuilder, faction guides, and Rules Arbiter;
- restored approved Rulebook production design and printable imposed booklet; and
- release-integrity checks that preserve the withdrawn historical packages while keeping current public surfaces synchronized.

## Recovery and authority

The originally published v0.6.2 and v0.6.3 packages remain preserved as historical evidence but are not current authority. The clean v0.6.3 release was reconstructed under the release-recovery process tracked in [#650](https://github.com/tymonius/Gauntlet/issues/650), including the player-facing Rulebook and terminology restoration completed in [PR #673](https://github.com/tymonius/Gauntlet/pull/673).

The GitHub tag and Release are created only after the deployed `gauntlet.run` surfaces and production Rules Arbiter pass the live-publication verification gate.
