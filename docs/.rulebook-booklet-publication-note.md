# Current Rulebook booklet publication

The Browser Rulebook's printable action points to the stable current-release path:

`/releases/v0.6.3-reconstructed/Gauntlet_v0.6.3_Rulebook_Booklet.pdf`

That file must be materialized from the approved Rulebook production pipeline, not from an alternate or legacy renderer. Use the **Publish current Rulebook booklet** workflow from a feature branch after player-facing Rulebook text changes. The workflow rebuilds and validates the approved booklet, materializes the imposed PDF into the current release payload, updates the release manifest and provenance, validates the current public contract, and commits the generated payload back to the feature branch for review.

The current publication contract verifies that the committed booklet provenance matches the current transformed player-facing Rulebook text so a stale public PDF cannot remain silently paired with a newer Browser Rulebook.
