Game mechanics, procedures, systems, and methods of play themselves are not protected by copyright merely because they appear in the rules.

### C. Card artwork and illustrations

The current illustrated-card release contains extensive pictorial material. Because the artwork pipeline includes generative-AI assistance, each image or image family must be classified for registration purposes as one of:

1. human-authored;
2. AI-assisted with protectable human modifications/selection/arrangement;
3. predominantly AI-generated material that should be expressly excluded from the copyright claim.

Do **not** claim raw AI-generated pictorial material as human authorship merely because it was prompted, selected, or incorporated into a card.

## 5. Preliminary trademark clearance — GAUNTLET

**Assessment: material conflict risk; do not file the bare word mark yet.**

Preliminary federal/public search surfaced at least these exact-mark conflicts:

### Federal registration 1,958,216 — GAUNTLET

- Exact word: **GAUNTLET**
- Goods include **computer programs for video games**
- Registered February 27, 1996
- Reported as **REGISTERED AND RENEWED**, with renewal activity in April 2026
- Ownership/assignment chain should be verified directly in USPTO TSDR/Assignment records before relying on any third-party database

This is the most important conflict because Gauntlet now has a public TTS implementation and an actively developed rules-aware digital game.

### Federal registrations 7,350,850 and 7,350,851 — GAUNTLET / GAUNTLET design

- Owner: Gauntlet Properties, LLC
- Registered April 9, 2024
- Services include retail/online retail store services featuring board, card, and fantasy games

These are not registrations for a tabletop game product itself, but they are in the same commercial ecosystem and must be considered in a likelihood-of-confusion analysis.

### Common-law / marketplace uses requiring review

Preliminary public search also found:
- Gauntlet Games, a tabletop/card-game retailer;
- The Gauntlet, a tabletop RPG publisher/producer;
- multiple historical/current games using "Gauntlet" in titles.

A full clearance should cover federal records, state records, common-law uses, domain/social handles, app stores, Steam, BoardGameGeek/tabletop databases, Kickstarter/BackerKit, and ordinary web commerce.

### Working trademark conclusion

The exact `GAUNTLET` word mark is **not cleared**. The existing live video-game registration is especially significant. A stylized logo filing or adding a subtitle may change registrability analysis but does not automatically eliminate infringement/confusion risk.

Before spending a USPTO filing fee, obtain a trademark attorney's clearance opinion on:
1. `GAUNTLET` for tabletop card games;
2. `GAUNTLET` for downloadable/digital games;
3. the current Gauntlet wordmark/logo;
4. any proposed composite/subtitle mark if the bare mark is too risky.

The current filing priority should be the copyright record because the first major faction-framework release was publicly released on July 20, 2026 and later releases followed rapidly.

- Substantial new material includes illustrated card presentation, expanded content, Rulebook revisions, and release-specific production material
- Must identify and exclude preexisting v0.6.x authorship and nonclaimable AI-generated material as required

Purpose: protect the substantial human-authored additions in the illustrated/TTS release.

#### Candidate 3 — software

Evaluate separate software registrations for:
- the rules-aware digital engine;
- Deckbuilder/tooling if commercially important;
- TTS-authored code where substantial.

### Trademark — clearance before filing

Do not submit an application for the bare `GAUNTLET` word mark until the federal/common-law clearance is complete and ownership of the mark is settled.

Current USPTO base filing fee: **$350 per class**, before possible additional fees.

### Entity ownership

Trademark ownership should be decided **before** filing, particularly if an intent-to-use application is contemplated.

Copyright registration does not need to be delayed solely to wait for formation of a future company: registrations can be made in the current copyright owner's name and copyright ownership can later be transferred by written assignment. Any transfer should be documented and, where useful, recorded.

The repository now establishes **TDS Games** as the provisional publishing imprint for Gauntlet through `config/publishing-authority.json`. That record deliberately separates publishing identity from IP ownership: Tymon Scott remains the stated copyright holder, and no legal-entity, trademark-ownership, or copyright-assignment status is asserted merely by use of the imprint.
