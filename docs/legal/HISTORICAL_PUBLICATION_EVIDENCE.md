# Gauntlet Historical Public-Distribution Evidence

**Prepared:** 2026-08-28  
**Purpose:** Establish the earliest known public distribution/use record relevant to copyright limitation-of-claim analysis and trademark chronology.

> This is an evidence file, not a final legal conclusion about statutory "publication." Copyright publication status must be determined for each work and distribution channel.

## Key finding

Gauntlet has a documented public history reaching back to **June 11, 2021**, not merely to the 2026 canonical release series.

The GitHub repository was created and made public on June 11, 2021. On that date the repository README evolved through three commits:

| Time (UTC) | Commit | Evidence |
| --- | --- | --- |
| 2021-06-11 08:04:49 | `d94c64ef6a0e05b1f26c8074e6df9a67b96f278a` | Initial public repository: "Gauntlet — Card game alpha testing" |
| 2021-06-11 08:06:20 | `942dbc78211933220d525d3bee0bf1681a94c6ca` | Added "Copyright ©2021 Tymon Scott." |
| 2021-06-11 09:14:47 | `fa5585b025332140dfdec2bc3f294aa8db16fb32` | Added public links to a copyable Google Sheets game document and a Tabletop Simulator Workshop mod |

At the final 2021 commit, the README stated:

- "Create a copy of this Google Sheets doc to your own Google Drive for use."
- Google Sheets document ID: `1mFpTH1dM9j0-15L9emBhFucWD3NMfLOasZQtFhT-9KU`
- Tabletop Simulator Workshop item ID: `2513539910`
- "Copyright ©2021 Tymon Scott."

The 2021 Git tree itself contained only `README.md`; the actual game materials were distributed through the linked external Google Sheets document and Tabletop Simulator Workshop item.

## 2021 archive correlation

The current repository preserves historical release stubs:

- `releases/v0.3.0/README.md`
- `releases/v0.3.1/README.md`
- `releases/v0.4.0/README.md`

The v0.4.0 archived README reproduces the same Google Sheets and Tabletop Simulator links that appeared in the June 11, 2021 root README, along with the 2021 copyright notice.

These archived release directories were materialized later and therefore **do not by themselves establish the 2021 release dates**. The contemporaneous 2021 commit history is the stronger evidence.

## Repository dormancy

The GitHub commit history shows no repository commits between **June 11, 2021** and **June 22, 2026**.

The first 2026 development/release commit after the dormant period was:

- 2026-06-22 11:29:04 UTC
- "Release v0.5.3 Attrition patch"

That commit was based directly on the 2021 repository state before the 2026 release-development branch was merged.

## Copyright implications

This changes the filing assumptions materially.

### v0.6.0 cannot be treated as the origin of all Gauntlet expression

Any rule text, card text, graphics, terminology, or other protectable expression already contained in the 2021 Google Sheet/TTS materials or in the v0.5.x releases is preexisting material for a later v0.6.0 registration.

The v0.6.0 filing should therefore claim only the human-authored new/revised expression contributed to that release and should identify appreciable preexisting published material in the limitation-of-claim section.

### A 2021 registration may be possible but requires recovery of the actual work

The current Git repository does not contain the 2021 game files themselves. A useful registration of the 2021 work would require recovering an authentic copy of the Google Sheets document, TTS save/assets, or another contemporaneous deposit-quality version.

The old external resource IDs should be preserved even if the resources are no longer publicly accessible.

### "Unpublished playtest project" is historically unreliable as a blanket label

The public 2021 README invited users to make their own copy of the Google Sheets document and linked a Tabletop Simulator Workshop mod. Later releases were also distributed publicly.

The project's current "unpublished playtest project" language therefore must not be relied upon as evidence of Copyright Office publication status.
