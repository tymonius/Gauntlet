# Gauntlet Copyright Filing Worksheets

**Prepared:** 2026-08-28  
**Status:** Filing-preparation draft — facts marked `VERIFY` must be resolved before submission.

> These worksheets are designed to make the Copyright Office filing mechanical once the authorship/provenance audit is complete. They are not a legal opinion.

## Filing rule that controls this project

Gauntlet contains material created with generative-AI assistance. U.S. Copyright Office guidance says an applicant registering a work containing AI-generated material must use the **Standard Application**, identify the human-authored contribution, and explicitly exclude AI-generated content that is more than de minimis.

Accordingly, do **not** use the cheaper Single Application for the filings below.

Current electronic Standard Application fee: **$65 per application** (subject to change before filing).

## Historical-publication warning

Repository history now establishes that Gauntlet had a public distribution surface on **June 11, 2021**: the public README linked a copyable Google Sheets game document and a Tabletop Simulator Workshop mod. The repository itself contained only the README, so the underlying 2021 game materials still need to be recovered and compared against later releases.

This means v0.6.0 must be treated as a later derivative/revised work unless the recovered historical materials show otherwise. See `docs/legal/HISTORICAL_PUBLICATION_EVIDENCE.md`.

## Proposed registration set

The safest working strategy is to register distinct works rather than treating the entire repository/release tree as one undifferentiated work:

1. **Gauntlet v0.6.0 Rulebook / game text**
2. **Gauntlet v0.6.0 card-and-component set** if the provenance audit shows a useful independent claim
3. **Gauntlet v0.7.0 Rulebook** as a derivative/revised literary work
4. **Gauntlet v0.7.0 illustrated card set** as a separate mixed literary/visual compilation
5. **Software** registrations later for commercially important codebases

The exact grouping should be checked against the Copyright Office deposit/unit-of-publication rules before submission.

# Worksheet E — software registrations

Do not bundle all repository code into a single filing by default. Candidate software works should be selected based on commercial importance and coherent authorship/version boundaries.

## Candidate works

1. **Gauntlet rules-aware digital engine**
2. **Gauntlet Deckbuilder**
3. **Rules Arbiter / rules tooling**
4. **Tabletop Simulator-authored scripts/tooling**, only to the extent Gauntlet owns the code

## Critical AI issue

Code produced by generative AI is subject to the same human-authorship analysis as AI-generated prose and artwork. Do not claim machine-generated code merely because it was generated from human instructions.

For each software candidate:
- identify human-written source;
- identify AI-generated source;
- identify human modifications that independently qualify as authorship;
- distinguish third-party/open-source dependencies;
- preserve license notices;
- follow Copyright Office computer-program deposit/redaction rules.

Software registration should follow a separate code-specific filing worksheet once a stable commercial version is chosen.
